EDVANCE TECH WEBSITE REDESIGN

This is a redesigned static website package for the existing GitHub Pages project.

DESIGN
- Deep navy, electric blue and cyan visual identity.
- Short copy and visual project cards.
- Uses the supplied EdVance Tech and AirXpress Eats logo artwork.
- Uses the supplied Triple S logo image as a separate business partner.
- Responsive mobile navigation and stacked mobile layouts.

FILES
- index.html, services.html, packages.html, contact.html
- projects/index.html and three project detail pages
- css/style.css and js/script.js
- Image/ contains the supplied brand images used by this package
- sitemap.xml includes the redesigned page URLs

BEFORE YOU PUBLISH
1. Make a backup or create a Git branch first.
2. Copy the package contents into the existing EdVance Tech Pty Ltd website folder, merging folders.
3. Keep your existing robots.txt, Google Search Console verification, and any unrelated image assets. The HTML keeps the existing Google verification token and canonical GitHub Pages domain.
4. Check that the public contact email edvancetechsolutions@gmail.com and phone number 073 314 1222 are correct.
5. The contact form opens the visitor's email app; it does not send or store enquiries on the website.
6. Preview locally before committing.

LOCAL PREVIEW
Open index.html in a browser, or use the VS Code Live Server extension.

PUBLISH
After checking all pages and image paths, commit and push the updated files to the existing main branch. Do not delete the repository or create a new GitHub Pages project.
